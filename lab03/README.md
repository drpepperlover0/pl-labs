## 📂 Структура лабораторной работы

В данной лабораторной работе представлены следующие файлы:

1. `minimum.py` — поиск минимального из трех целых чисел с использованием ветвлений (`if`/`elif`/`else`).

4. `variant.py` — определение категории игрового ресурса по введенному значению от 0 до 100 (индивидуальный вариант №9).

5. `leap.py` — Определение высокосного года (с ответами вида: `Да` и `Нет`).

## ⚙️ Доп объяснения и ответы на вопросы:

* **Выбор `and` / `or`:** Оператор `and` нужен, когда требуется, чтобы все условия оказались истинными сразу. Например, чтобы убедиться, что точка лежит в заданном прямоугольнике: `0 <= x <= 5 and 0 <= y <= 3` - оба диапазона должны соблюдаться. Оператор `or`, напротив, срабатывает, если верно хотя бы одно из условий. Например, при проверке баллов можно использовать `or`, чтобы определить, вышло ли значение за допустимые границы - достаточно, чтобы оно оказалось меньше минимума или больше максимума.

* **Порядок ветвей:** Цепочка `if-elif-else` проверяет условия последовательно сверху вниз и выполняет тело **только первой** ветви. Важно выстраивать проверки в строгом порядке (например, отсекать границы в самом начале, а общие случаи оставлять на `elif`/`else`).

* **Поведение при равенстве значений:** При работе со строгими `(<, >)` и нестрогими `(≤, ≥)` неравенствами важно, чтобы граничные значения *обрабатывались однозначно*. Это значит: если значение равно точке раздела интервалов (например, порогу между категориями 14 и 15), условие должно чётко определять, к какому из соседних интервалов оно относится. Цель - избежать ситуации, когда одно и то же значение «захватывается» сразу двумя интервалами, то есть возникает пересечение решений.
