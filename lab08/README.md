## 📋 Данные индивидуального варианта №7

Предметная область — **настольные игры**, поле `amount` — количество баллов.

```python
records = [
```

## ⚙️ Ответы на вопросы

- **Выбор структуры данных для каждого задания:** Для подсчёта частоты слов (задание 1) выбран словарь `dict`, так как он хранит пары «слово — счётчик» и позволяет быстро обновлять частоту по ключу. Для работы с темами (задание 2) применены множества `set`, поскольку они убирают дубликаты и поддерживают операции пересечения и объединения. Для представления записи (задание 3) взят словарь `dict`, а для пары связанных значений — кортеж `tuple`. В индивидуальном задании (вариант №7) итоговые баллы по категориям накапливаются в словаре `dict` при обходе исходного списка словарей в режиме чтения.

- **Работа метода `.get()`:** Вызов `словарь.get(ключ, значение_по_умолчанию)` безопасно возвращает значение по ключу, а если такого ключа ещё нет — подставляет заданное значение по умолчанию (например, `0`). Это избавляет от ошибки `KeyError` и позволяет лаконично увеличивать счётчики или суммы за один шаг.

- **Зачем сортировать множество перед выводом:** Множество (`set`) не гарантирует порядок элементов и не поддерживает обращение по индексу, поэтому прямой вывод или обход может выглядеть непредсказуемо. Передача результата в `sorted(...)` приводит данные к привычному упорядоченному списку, что удобно для стабильного вывода и проверок.

- **Почему запись удобно представлять словарём:** Запись состоит из именованных характеристик объекта, и словарь позволяет обращаться к ним по понятным именам ключей, а не запоминать порядковые номера позиций. Кроме того, словарь легко изменять по мере работы программы: можно обновить значение существующего поля или добавить новое без создания новой структуры, тогда как кортеж лучше подходит для краткой фиксированной пары значений.
