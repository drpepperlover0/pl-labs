## 📂 Структура лабораторной работы

В данной лабораторной работе (`lab10`) представлены следующие файлы:

1. `main.py` — основная программа. Выполняет надёжный ввод положительного целого числа, считывает матрицу из `matrix.txt`, вычисляет суммы строк, столбцов и результат по индивидуальному варианту, после чего при отсутствии ошибок сохраняет итоги в `report.txt`.

2. `files_lab.py` — модуль работы с текстовыми файлами:
   - `read_matrix(path)` — читает матрицу из текстового файла в кодировке UTF-8 и проверяет корректность её структуры и значений;
   - `selected_sum(matrix)` — вычисляет сумму элементов матрицы в диапазоне от `-2` до `3` включительно (Вариант №7); для пустой матрицы возвращает `0`.

3. `table.py` — модуль функций для обработки таблиц:
   - `row_sums(matrix)` — вычисляет суммы элементов по каждой строке таблицы;
   - `column_sums(matrix)` — вычисляет суммы элементов по каждому столбцу таблицы;
   - `diagonal_pattern(size)` — формирует квадратную матрицу с диагональным узором;
   - `transform(matrix)` — возвращает новую матрицу той же формы, увеличивая положительные элементы на `5` (Вариант №7 из работы №9), не меняя исходную;
   - `factorial(number)` и `factorial_iterative(number)` — рекурсивная и итеративная реализации факториала.

4. `test_files.py` — модуль автоматических проверок чтения матрицы, индивидуального варианта и обработки ошибочных данных с помощью `assert`.

5. `matrix.txt` — входной текстовый файл с размерами и элементами исходной матрицы.

6. `report.txt` — выходной файл с результатами вычислений, формируемый программой.

## 📄 Формат входного файла и пример отчёта

Файл `matrix.txt` сохраняется в кодировке UTF-8: в первой строке указываются два положительных целых числа (количество строк и столбцов), а в следующих строках — элементы матрицы в точном соответствии с заданными размерами.

Содержимое используемого `matrix.txt`:

```text
2 3
1 -2 3
4 0 -6
```

После чтения функция `read_matrix()` возвращает матрицу `[[1, -2, 3], [4, 0, -6]]`. Из её элементов в отрезок `[-2; 3]` попадают `1`, `-2`, `3` и `0`, что даёт сумму `2`.

Сформированный файл `report.txt`:

```text
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
Результат варианта: 2
```

## ⚙️ Ответы на вопросы:

- **Отличие ошибок формата от ошибок доступа:** Ошибки формата (`ValueError`) возникают тогда, когда файл удалось открыть и прочитать, но само его содержимое не соответствует ожидаемым правилам — например, в ячейке встретились буквы вместо чисел, не хватает столбцов или размеры не совпадают с заголовком. Ошибки доступа (`FileNotFoundError`, `OSError`) связаны с работой файловой системы: отсутствием файла по указанному пути, нехваткой прав или невозможностью открыть файл. Отдельно `UnicodeError` сообщает о проблеме декодирования текста в нужной кодировке, и в блоках `except` его перехватывают раньше `ValueError`, так как `UnicodeError` является его подклассом.

- **Почему отчёт открывается для записи после проверки входа:** Открытие файла в режиме `"w"` мгновенно стирает его предыдущее содержимое. Если открыть `report.txt` до чтения и проверки `matrix.txt`, то при обнаружении ошибки во входных данных старый отчёт уже окажется уничтожен, хотя новый сформировать невозможно. Выполнение записи в ветке `else` после успешной проверки гарантирует, что при любых проблемах с входным файлом прежний `report.txt` останется нетронутым.

- **Зачем используются `with open()` и `encoding="utf-8"`:** Контекстный менеджер `with` гарантирует автоматическое закрытие файла и сброс буфера при выходе из блока, даже если внутри возникло исключение. Явное указание `encoding="utf-8"` обеспечивает единообразное чтение и запись кириллицы независимо от системных настроек ОС.
