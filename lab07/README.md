## ⚙️ Ответы на вопросы:

* **Разница между `return` и `print()`:** Инструкция `return` возвращает значение из функции в то место, откуда она была вызвана, сохраняя результат для вычислений в программе. Функция `print()` лишь выводит информацию на экран терминала для пользователя и возвращает `None`.

* **Локальные переменные и параметры:** Параметры — это переменные, принимающие значения при вызове функции. Локальные переменные создаются и используются исключительно внутри тела функции. Ни параметры, ни локальные переменные недоступны за пределами функции.

* **Тест для обнаружения ошибки:** Если в `average(numbers)` не учесть условие с пустым списком `[]`, то для него тест `assert average([]) is None` упадет с ошибкой `ZeroDivisionError`, так как деление на ноль в Python запрещено.
