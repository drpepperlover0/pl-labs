### Ответы на вопросы:

* **Отличие `/` от `//`:** Оператор `/` выполняет обычное деление, возвращая результат с типом данных `float` (например, `5 / 2 == 2.5`). Оператор `//` выполняет целочисленное деление (с округлением вниз до ближайшего целого), не включая остаток (например, `5 // 2 == 2`, а также `-5 // 2 == -3`).

* **Смысл остатка (`%`):** Операция возвращает ту часть делимого, которая осталась после того, как из него вычли максимально возможное количество полных «вхождений» делителя — то есть то, что не удалось распределить на равные целые части по размеру делителя. (например, `5 % 2 == 1`, т.к. `2 * 2 + 1 = 5`).

* **Неточность типа данных `float`:** Этот тип хранит вещественные числа в двоичном (бинарном) виде, из-за чего десятичные дроби (например, `0.1 + 0.2`) представляются приближенно (получается `0.30000000000000004`). Форматирование вывода (например, `:.2f`) визуально округляет отображаемое число на экране, но не меняет то приближенное значение, которое существует в памяти компьютера.
