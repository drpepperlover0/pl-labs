## 📂 Структура лабораторной работы

В данной лабораторной работе представлены следующие файлы:

1. `statistics.py` — расчет количества, суммы, минимума, максимума и среднего арифметического (с округлением до двух знаков) для списка целых чисел.

2. `transform.py` — создание нового списка с заменой отрицательных чисел их модулями при сохранении первоначального списка.

3. `positions.py` — поиск всех индексов максимального элемента в списке в порядке возрастания с использованием `enumerate()`.

4. `variant.py` — фильтрация чисел, не кратных 3 (индивидуальный вариант №7) с выводом исходного порядка, количества, суммы и отсортированной по возрастанию копии списка.

5. `dop.py` — удаление дубликатов из списка с сохранением порядка их первого появления (без использования `set()`).

## ⚙️ Ответы на вопросы:

* **Отличие `append()` от присваивания по индексу:** Метод `append()` динамически добавляет новый элемент в конец списка, увеличивая его длину на 1. Присваивание по индексу (`items[i] = value`) меняет значение существующего элемента итерируемой последовательности по указанному индексу.

* **Отличие `sorted()` от `.sort()`:** Функция `sorted(items)` создает и возвращает **новый** отсортированный список, не изменяя исходный. Метод `.sort()` сортирует список «на месте», изменяя порядок элементов в исходной последовательности, возвращая `None`.
