## ⚙️ Дополнительные объяснения

* **Различие строки и числа:** строка (`str`) хранит текст, например "23", а число (`int` или `float`) используется для вычислений. Например, "2" + "3" даст "23", а 2 + 3 даст 5. Для преобразования ввода используются `int()` и `float()`.
* **Порядок вычислений:** сначала выполняются умножение (*) и деление (/), затем сложение (+) и вычитание (-). Скобки позволяют изменить порядок выполнения.
* **Временная переменная при обмене:** необходима для безопасного обмена значениями между двумя переменными без их перезаписи и потери данных в процессе присваивания.
* **Форматирование денежного вывода:** для вывода суммы с двумя знаками после запятой используется `:.2f` а f-строке.
   
   Например, `print(f'{cost:.2f}')`: если `cost` будет содержать значение `37.5`, то будет выведено `37.50`
